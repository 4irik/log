Трамплин: рекурсия любой глубины в PHP

2026-11-14

В функциональных языках, в отличие от PHP и прочих мейнстримных языков, нет циклов, их место занимает рекурсия. Но в том же самом PHP глубина рекурсивного вызова ограничена, ну и как бы, в большинстве случаев, это не важно, просто пишем через итерации. Но мой lisp-интерпретатор написан на PHP, а значит, если я хочу чтобы он полноценно работал, нужно чтобы он обрабатывал рекурсивные вызовы любой вложенности.

Начнём с анализа того что есть в PHP:

function show(string $label): void
{
    echo $label . "\n";
    foreach (debug_backtrace(DEBUG_BACKTRACE_IGNORE_ARGS) as $i => $frame) {
        $fn = $frame['function'] ?? '?';
        $line = $frame['line'] ?? '-';
        echo "  #$i $fn line $line\n";
    }
}

function fact_rec(int $n): int {
    if ($n === 0) {
        show('fact rec at n=0');
        return 1;
    }

    return fact_rec($n - 1) * $n;
}

function fact_iter(int $n, int|float $acc = 1): int|float {
    if ($n === 0) {
        show('fact iter at n = 0');
        return $acc;
    }

    return fact_iter($n - 1, $acc * $n);
}

fact_rec(10);
fact_iter(10);

И, при достаточно большом начальном входном значении, мы получаем Allowed memory size. Для рекурсивной версии функции я получил выход за пределы памяти при вычислении факториала от 185_000, для итеративной формы — 220_000.

Так вот, есть способ заставить языки без TCO, подчищать стек вызовов, если он не нужен. Называется трамплин. Но, к сожалению, он требует модификаций исходной функции:

  1. нужно перевести форму в итеративную форму (пример — fact_iter) чтобы каждый вызов был независим и получал, в качестве аргументов, все необходимые данные для вычисления;
  2. функция должна вернуть не вызов себя же, а специальный контейнер в котором заключён этот самовызов.
final class Thunk
{
    public function __construct(public Closure $resume) {}
}

function trampoline(Closure $start): mixed
{
    $value = $start();
    while ($value instanceof Thunk) {
        $value = ($value->resume)();
    }
    return $value;
}

function fact_trump(int $n, int|float $acc = 1): Thunk|int|float {
    if ($n === 0) {
        show('fact trump at n = 0');
        return $acc;
    }

    return new Thunk(static fn() => fact_trump($n - 1, $acc * $n));
}

trampoline(static fn() => fact_trump(1_000_000));

И, видим такой вывод стека:

fact trump at n = 0
  #0 show line 81
  #1 fact_trump line 85
  #2 {closure:fact_trump():85} line 13
  #3 trampoline line 90

это для факториала миллионного числа! Напоминаю что две предыдущих реализации получили OOM уже в районе 200_000.

PS. int|float в итеративной форме функции указано т.к. на больших числах мы выходим за пределы int и интерпретатор преобразует число во float.
